# Alexandria — v0.1 Scaffold Implementation Plan

## Context

Building Alexandria from scratch: a self-hosted reading server that replaces Calibre-web with a
first-class EPUB reading experience, TTS, and library management. The immediate goal (v0.1) is a
working project scaffold — correct architecture in place, domain model defined, auth and book
library functional, frontend reachable — so v0.5 (epub rendering) and v0.8 (TTS) can build on
solid ground without structural rework.

---

## Technology Decisions

| Concern | Choice | Reason |
|---|---|---|
| HTTP framework | Fiber v2 | Fast, ergonomic, great middleware |
| Database | SQLite via GORM | Zero-dependency personal server deployment |
| SQLite driver | `github.com/glebarez/sqlite` | Pure Go (no CGO), works in Alpine Docker |
| Auth | JWT HS256 + bcrypt | Simple, stateless, good-enough for personal server |
| Frontend | Vue 3 + TypeScript + Vite | Reactive state for reading position, TTS, library |
| State mgmt | Pinia | Vue 3 native, TypeScript-first |
| TTS | Browser Web Speech API (v0.8) | No server deps, pause/resume/position built-in |
| EPUB rendering | epub.js on frontend, Go serves file | Go handles auth; epub.js handles rendering |
| File IDs | UUID v4 | Standard, collision-free |
| Go module | `alexandria` | Simple, not published |

## API Endpoints

```
POST   /api/v1/auth/register
POST   /api/v1/auth/login
POST   /api/v1/auth/refresh

GET    /api/v1/me

GET    /api/v1/books                 # ?search=&author=&genre=&page=&limit=
POST   /api/v1/books                 # multipart: file + optional metadata JSON
GET    /api/v1/books/:id
PUT    /api/v1/books/:id
DELETE /api/v1/books/:id
GET    /api/v1/books/:id/content     # streams the epub/pdf file (auth-protected)
GET    /api/v1/books/:id/cover       # streams the cover image

GET    /api/v1/books/:id/progress
PUT    /api/v1/books/:id/progress

GET    /health
```

All `/api/v1/*` routes except auth require `Authorization: Bearer <token>` header.

## Key Implementation Notes

### EPUB Parser (stdlib only)
1. `archive/zip.OpenReader` on the epub file
2. Parse `META-INF/container.xml` → find OPF path
3. Parse OPF XML → extract `dc:title`, `dc:creator`, `dc:description`, `dc:publisher`, `dc:date`, `dc:subject`
4. Find cover image from manifest (item with `properties="cover-image"` or id containing "cover")
5. Extract cover to data dir as `books/{id}/cover.jpg`

### Auth Flow
- Register: hash password with bcrypt (cost 12), store user, return tokens
- Login: verify bcrypt hash, issue access token (15min) + refresh token (7d)
- Access token payload: `{ sub: userID, exp }`
- Refresh: validate refresh token, issue new access token
- JWT secret from `JWT_SECRET` env var

### File Storage
- Books stored at `{DATA_DIR}/books/{bookID}/original.epub` (or `.pdf`)
- Covers at `{DATA_DIR}/books/{bookID}/cover.jpg`
- `DATA_DIR` defaults to `./data`

### Config (env vars)
```
PORT=8080
DATA_DIR=./data
DB_PATH=./data/alexandria.db
JWT_SECRET=changeme
JWT_EXPIRY=15m
REFRESH_EXPIRY=168h
```

### Frontend Dev Proxy
Vite config proxies `/api` to `http://localhost:8080` in dev mode.
Go serves `client/dist/` at `/` in production (via `fiber.Static`).

### Docker
Multi-stage Dockerfile:
1. `node:20-alpine` — `npm ci && npm run build` in `client/`
2. `golang:1.22-alpine` — `go build -o server ./cmd/server` (CGO_ENABLED=0)
3. `alpine:latest` — copy binary + `client/dist/`

`docker-compose.yml` mounts `./data:/app/data` for persistence.

## Verification

After implementation, verify end-to-end with:

```bash
# 1. Start the stack
docker compose up --build

# 2. Register a user
curl -X POST http://localhost:8080/api/v1/auth/register \
  -H "Content-Type: application/json" \
  -d '{"username":"alex","password":"secret123"}'

# 3. Login
TOKEN=$(curl -s -X POST http://localhost:8080/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"alex","password":"secret123"}' | jq -r '.access_token')

# 4. Upload a book
curl -X POST http://localhost:8080/api/v1/books \
  -H "Authorization: Bearer $TOKEN" \
  -F "file=@/path/to/book.epub"

# 5. List books
curl http://localhost:8080/api/v1/books \
  -H "Authorization: Bearer $TOKEN"

# 6. Open browser → http://localhost:8080 → login → see library
# 7. Run e2e tests
cd test && pip install -r requirements.txt && pytest -v
```

Also run: `make dev` for local development workflow.
