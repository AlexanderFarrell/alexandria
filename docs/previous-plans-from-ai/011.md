# Plan: Mobile Responsiveness Improvements

## Context

Alexandria is a self-hosted reading server with a desktop-first UI. The user wants:
1. **BookDetailModal buttons hard to see** — `btn-ghost` uses `color: var(--text-muted)` (#8a8494) with a near-invisible border (`var(--border)` = #2a2a38 on #1a1a24 background)
2. **Upload modal queue scrollable** — uploading many books grows the modal off-screen with no scroll
3. **General mobile layout** — sidebars cover too much space, no responsive breakpoints

---

## Changes

### 1. `client/src/style.css` — Fix btn-ghost visibility

Change `.btn-ghost` text color from `var(--text-muted)` → `var(--text)` so button labels are clearly legible. The border already exists (`var(--border)`) but the muted text is the core problem.

```css
.btn-ghost {
  background: transparent;
  color: var(--text);           /* was: var(--text-muted) */
  border: 1px solid var(--border);
}
```

### 2. `client/src/views/LibraryView.vue`

**a) Scrollable upload queue** — The `.upload-queue` list grows unbounded inside the modal. Add:
```css
.upload-queue {
  max-height: 280px;
  overflow-y: auto;
}
```

**b) Mobile sidebar toggle** — On `≤768px`, hide sidebar and show a "Filters" toggle button in the toolbar. Track with `showFilters` ref.

Template changes:
- Add `<button class="btn-ghost filter-toggle" @click="showFilters = !showFilters">Filters</button>` in toolbar (visible only on mobile via CSS)
- Bind `:class="{ visible: showFilters }"` on the `<aside class="sidebar">`
- Add `const showFilters = ref(false)` to script

CSS additions:
```css
.filter-toggle { display: none; }

@media (max-width: 768px) {
  .layout { flex-direction: column; padding: 1rem; gap: 1rem; }
  .sidebar { display: none; width: 100%; position: static; max-height: 300px; overflow-y: auto; }
  .sidebar.visible { display: flex; }
  .filter-toggle { display: inline-flex; }
  .grid { grid-template-columns: repeat(auto-fill, minmax(130px, 1fr)); gap: 1rem; }
  .search-wrap { min-width: 0; max-width: none; }
}

@media (max-width: 400px) {
  .grid { grid-template-columns: repeat(2, 1fr); }
}
```

### 3. `client/src/components/BookDetailModal.vue` — Mobile layout

On mobile (≤600px) stack left-col on top of right-col, with cover+rating in a horizontal row to save vertical space. Also wrap action buttons.

```css
@media (max-width: 600px) {
  .modal-body { flex-direction: column; padding: 1rem; gap: 1rem; }
  .left-col { flex-direction: row; width: 100%; gap: 1rem; align-items: flex-start; }
  .cover-wrap { width: 90px; flex-shrink: 0; }
  .modal-actions { flex-wrap: wrap; padding: 0.75rem 1rem; gap: 0.5rem; }
  .right-actions { flex-wrap: wrap; gap: 0.5rem; }
}
```

### 4. `client/src/views/ListsView.vue` — Mobile lists panel

On mobile, stack the layout vertically. The lists panel becomes a compact horizontal scroll area at top.

```css
@media (max-width: 768px) {
  .layout { flex-direction: column; padding: 1rem; gap: 1rem; }
  .lists-panel { width: 100%; position: static; max-height: 180px; overflow-y: auto; }
}
```

### 5. `client/src/components/NavBar.vue` — Reduce mobile padding

```css
@media (max-width: 480px) {
  .navbar { padding: 0 1rem; }
}
```

6. Lists page → panel is compact/scrollable at top, books grid below
