# Expandable EPUB Contents Tree

## Summary
- Add collapsible branches to the reader contents tree so long EPUB tables of contents are easier to scan.
- Default behavior: when the contents panel opens, branches are collapsed except for the branch containing the current active chapter/location.
- Keep existing navigation behavior intact for section and fragment links.

## Key Changes
- Update [ReaderNavTree.vue](/home/alexander/Projects/alexandria/client/src/components/reader/ReaderNavTree.vue) to manage shared expansion state across the recursive tree.
- Generate stable tree node keys from ancestry/index, not just label text, so expand/collapse state cannot collide across repeated labels.
- Render a disclosure control for any item with `children`.
- For group-only nodes, use the row as the toggle.
- For nodes that are both navigable and parents, keep the title click as navigation and add a separate chevron/disclosure button for expand/collapse.
- Auto-expand the active item’s ancestor path on mount and whenever `activeSectionId` or `activeFragment` changes; merge that path into the current expanded set instead of resetting all user toggles.
- Add disclosure affordances and accessibility attributes (`aria-expanded`, `aria-controls`, accessible toggle labels), plus collapsed/expanded styling.
- Keep [ReaderView.vue](/home/alexander/Projects/alexandria/client/src/views/ReaderView.vue) API usage the same unless minor sidebar spacing/styling adjustments are needed.
- No backend, manifest, or shared `ReaderNavItem` type changes.

## Test Plan
- Run `npm --prefix client run type-check`.
- Manually verify with EPUBs that have:
  - Flat contents only: navigation still works unchanged.
  - Nested non-clickable group headings: groups expand/collapse correctly.
  - Clickable parents with children: label navigates, chevron toggles.
  - Fragment links inside a section: active highlighting still works and the containing branch auto-expands.
  - Navigation via footer buttons or in-content links: the current branch remains visible when reopening contents.
- Check desktop and mobile sidebar behavior so disclosure controls remain easy to tap and reduce scrolling.

## Assumptions
- Expansion state is session-local to the current reader view; it is not persisted in `localStorage`.
- The branch containing the current reading location is always reopened after navigation, even if the user had collapsed it earlier.
- No new automated frontend tests are added unless the project first adds a frontend test harness.
