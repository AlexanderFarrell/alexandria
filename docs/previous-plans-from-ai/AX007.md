# Plan: Library Navigation & Organization (AX005)

## Context
The library view currently has no sticky toolbar (search/upload scroll out of view), no table view, no multi-select, no publisher/year sidebar filters, and no keyboard shortcuts. This plan adds all of those features to make the library significantly more navigable and manageable.

---

### Phase 3 — `useSelection` Composable
**New file:** `client/src/composables/useSelection.ts`

Manages ephemeral multi-select state (not in Pinia store — view-local):

```typescript
export function useSelection(books: () => Book[]) {
  const selectedIds = ref<Set<string>>(new Set())
  // Always create a new Set on mutation (Vue reactivity)
  const isSelected = (id: string) => selectedIds.value.has(id)
  const selectedCount = computed(() => selectedIds.value.size)
  const hasSelection = computed(() => selectedIds.value.size > 0)
  const allSelected = computed(() => books().length > 0 && books().every(b => selectedIds.value.has(b.id)))
  const selectedBooks = computed(() => books().filter(b => selectedIds.value.has(b.id)))
  function toggle(id: string) { selectedIds.value = new Set(selectedIds.value); selectedIds.value.has(id) ? selectedIds.value.delete(id) : selectedIds.value.add(id) }
  function selectAll() { selectedIds.value = new Set(books().map(b => b.id)) }
  function clearSelection() { selectedIds.value = new Set() }
  return { selectedIds, isSelected, selectedCount, hasSelection, allSelected, selectedBooks, toggle, selectAll, clearSelection }
}
```

**9.7 Batch handlers:**
```typescript
async function onBatchAddToList(listId: string) {
  await Promise.all([...selection.selectedIds.value].map(id => listsStore.addBook(listId, id)))
  selection.clearSelection()
}
async function onBatchDelete() {
  await Promise.all([...selection.selectedIds.value].map(id => books.deleteBook(id)))
  selection.clearSelection()
  // refresh sidebar counts
}
```

**9.8 Hotkeys** via `useHotkeys`:
- `/` → focus search (not when input focused)
- `Ctrl+K` → focus search (even when input focused)
- `U` → open upload modal
- `T` → toggle view mode
- `A` → select all / clear all
- `Escape` → clear selection, then close open modal (priority order)

**9.9 Clear selection on filter change** — call `selection.clearSelection()` in `setAuthorFilter`, `setGenreFilter`, `setPublisherFilter`, `setYearFilter`, and `onSearch`.

**9.10 `onMounted`** — add `books.fetchPublishers()` and `books.fetchYears()`.

**9.11 `onDeleted`/`onSaved`** — refresh publishers and years too.

```typescript
async function onBatchRemove() {
  if (!listsStore.currentList) return
  await Promise.all([...selection.selectedIds.value].map(id =>

}
```

## Verification

1. **Sticky toolbar**: Scroll down in library — search and "+ Add book" should stay visible
2. **Table view**: Click toggle — books render as table with sortable column headers
3. **Multi-select grid**: Hover BookCard — checkbox appears; click to select; BatchActionBar appears at bottom
4. **Multi-select table**: Checkbox column; header "select all" checkbox
5. **Batch add to list**: Select 3 books → BatchActionBar → pick list → all 3 added
6. **Batch delete**: Select books → delete → confirm inline → books removed, sidebar counts updated
7. **Publisher/Year sidebar**: Click publisher → only that publisher's books shown; same for year
8. **Remove from list**: In ListsView, select books → BatchActionBar → remove → books gone from list
9. **Hotkeys**: Press `/` → search focused; `U` → upload modal opens; `T` → view toggles; `Escape` → closes modals; `A` → selects all
10. **Ctrl+K**: Opens search even when another input is focused
