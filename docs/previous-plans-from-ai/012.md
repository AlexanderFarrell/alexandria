# Plan: Online Metadata Lookup Feature

## Context

Alexandria currently extracts metadata from EPUB/PDF files on upload and allows manual editing via the BookEditModal. This feature adds a "Search Online" button to the edit modal that queries external metadata providers (Google Books, Open Library), shows normalized results, lets the user pick one to pre-fill the form, and optionally replaces the book cover — reducing manual entry and enriching incomplete records.

---

## Step-by-Step Implementation

### 1. `app/ports/metadata.go` — Port interface

```go
package ports

import "context"

type MetadataResult struct {
    Title         string
    Authors       []string
    Description   string
    CoverURL      string
    Publisher     string
    PublishedDate string   // raw: "YYYY", "YYYY-MM", or "YYYY-MM-DD"
    ISBN          string
    Language      string
    Tags          []string
    Source        MetadataSource
    ExternalURL   string
}

type MetadataSource struct {
    ID   string
    Name string
    Link string
}

type MetadataQuery struct {
    Q      string
    Title  string
    Author string
    ISBN   string
}

type MetadataProvider interface {
    ID() string
    Search(ctx context.Context, query MetadataQuery) ([]MetadataResult, error)
}
```

`PublishedDate` is a raw string because providers return year-only, month, or full date; normalization happens in the frontend.

### 2. `infra/metadata/google.go` — Google Books provider

- Endpoint: `https://www.googleapis.com/books/v1/volumes?q=...` (no API key, public)
- Query: `isbn:<isbn>` if ISBN set; else `intitle:<title>+inauthor:<author>`; else free-text
- Map `volumeInfo.{title, authors, description, publisher, publishedDate, language, categories, infoLink, imageLinks.thumbnail, industryIdentifiers}`
- Rewrite `http://` thumbnail URLs to `https://` (avoid mixed-content blocks)
- Use `http.NewRequestWithContext` (timeout from caller's context, not client)

### 3. `infra/metadata/openlibrary.go` — Open Library provider

- Search: `https://openlibrary.org/search.json?title=...&author=...&limit=10&fields=key,title,author_name,first_publish_year,isbn,publisher,language,subject,cover_i`
- ISBN direct: `https://openlibrary.org/isbn/<isbn>.json` (different shape, separate struct)
- Cover: `https://covers.openlibrary.org/b/id/<cover_i>-M.jpg`
- `ExternalURL`: `https://openlibrary.org<key>`
- Cap `subject` array at 10 for tags

### 4. `app/services/metadata.go` — MetadataService

```go
type ProviderError struct {
    Provider string `json:"provider"`
    Message  string `json:"message"`
}

type MetadataService struct {
    providers []ports.MetadataProvider
    timeout   time.Duration   // 7 seconds default
}

func NewMetadataService(providers []ports.MetadataProvider) *MetadataService

func (s *MetadataService) Search(ctx context.Context, q ports.MetadataQuery) (
    results []ports.MetadataResult, errs []ProviderError, err error)
```

Fan-out: `context.WithTimeout(ctx, 7s)`, one goroutine per provider, **buffered channel** `make(chan providerResult, len(providers))` so goroutines can exit cleanly even after timeout. Collect all, return combined results + per-provider errors.

### 5. `app/services/book.go` — Cover URL download

Add `CoverURL *string` to `BookUpdate`. In `Update()`, after applying other fields:
```go
if u.CoverURL != nil {
    if err := s.applyCoverFromURL(ctx, book, *u.CoverURL); err != nil {
        log.Printf("apply cover from URL for book %s: %v", book.ID, err)
        // non-fatal — continue with rest of update
    }
}
```

`applyCoverFromURL` private method:
- Parse URL; reject if scheme ≠ `http`/`https` or host is `localhost`/`127.*`/`::1` (SSRF protection)
- `http.Get` with `context`, read up to 10 MB with `io.LimitReader`, validate `Content-Type` starts with `image/`
- `s.store.Save(ctx, "books/{id}/cover.jpg", body)`
- Set `book.CoverPath`

### 14. `client/src/components/MetadataSearchModal.vue` — Search modal

**Props:** `initialTitle?: string`, `initialAuthor?: string`
**Emits:** `close`, `apply(result: MetadataResult, replaceCover: boolean)`

**Behavior:**
- Pre-fill search from props; auto-search on mount if title is non-empty
- Results as 2-column grid: cover thumbnail + title/authors/publisher/year/source badge
- Clicking a card selects it (highlights); clicking again deselects
- "Also replace cover image" checkbox shown when selected result has `cover_url`
- Provider error warnings shown as small dismissible badges (non-blocking)
- "Apply to form" button enabled only when a result is selected

### 15. `client/src/components/BookEditModal.vue` — Wire search modal

Add:
```typescript
const showMetadataSearch = ref(false)
const pendingCoverURL = ref<string | null>(null)

function onApplyMetadata(result: MetadataResult, replaceCover: boolean) {
  // Only overwrite non-empty values from result
  if (result.title) form.title = result.title
  if (result.authors.length) form.author = result.authors.join(', ')
  if (result.description) form.description = result.description
  if (result.publisher) form.publisher = result.publisher
  if (result.language) form.language = result.language
  if (result.isbn) form.isbn = result.isbn
  if (result.published_date) {
    const d = result.published_date
    form.publishedAt = d.length === 4 ? d + '-01-01' : d.slice(0, 10)
  }
  if (result.tags?.length) form.genresRaw = result.tags.join(', ')
  if (replaceCover) pendingCoverURL.value = result.cover_url ?? null
  showMetadataSearch.value = false
}
```

Add `cover_url: pendingCoverURL.value ?? undefined` to the `onSubmit` update payload.

Add "Search Online" button near the modal header, `MetadataSearchModal` mounted with `v-if="showMetadataSearch"`.

## Data Flow

```
User clicks "Search Online" in BookEditModal
  → MetadataSearchModal opens, auto-searches with book's title + author
  → GET /api/v1/metadata/search?title=...&author=...
    → MetadataService.Search fans out to Google Books + Open Library (parallel, 7s timeout)
    → Returns { results: [...], errors: [...] }
  → User selects a result card, optionally checks "replace cover"
  → Clicks "Apply to form" → emits 'apply'
  → BookEditModal.onApplyMetadata fills form fields
  → User reviews, may edit, clicks "Save changes"
  → PUT /api/v1/books/:id { ..., cover_url: "https://..." }
    → BookService.Update applies fields, downloads & stores cover if cover_url set
```
